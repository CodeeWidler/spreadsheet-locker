# Spreadsheet Locker

Lock every sheet in an Excel (.xlsx) workbook with a password, right in your browser.

**Use it:** https://codeewidler.github.io/spreadsheet-locker/

1. Load an .xlsx file.
2. Enter a password.
3. Click **Lock and save**. You get a copy named `<original> locked.xlsx`.

The locked copy protects every cell on every sheet, locks the sheet tabs (no adding, deleting, renaming or moving sheets), can block selecting and copying cells, and can open read-only unless the password is entered.

Your file never leaves your computer. All the locking runs in the browser.

Excel's built-in protection stops normal users, not someone using password-removal tools.
